### 📊 PostgreSQL Projects (Data Analysis)

Here are the projects I have developed to practice advanced database querying, optimization, and data analytics:

* **[r_sales_p1](https://github.com/MGMADHAV-bot/r_sales_p1)**: **Retail Sales Data Analysis** – Conducted exploratory data analysis (EDA) using advanced SQL queries to identify critical sales trends, customer behavior patterns, and revenue-generating insights.
* **[library_mg_p2](https://github.com/MGMADHAV-bot/library_mg_p2)**: **Library Management System** – Designed and implemented a robust database-driven system in PostgreSQL for tracking book rentals, managing active members, and automating transactions.
* **[netflix_p3](https://github.com/MGMADHAV-bot/netflix_p3)**: **Netflix Content Analysis** – Queried and analyzed Netflix's content catalog to extract insights regarding regional content distribution, release year trends, and genre structures.
* **[spotify_p4](https://github.com/MGMADHAV-bot/spotify_p4)**: **Spotify Data Analysis** – Performed analytical queries on music streaming datasets to evaluate artist performance, track popularity metrics, and user preferences.
